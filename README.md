# 📊 Simple Data Filtering

## Task 8 - Level 1 - Day 8

A beginner-friendly Python project that creates a collection of student records and filters students based on marks, age, department, and multiple conditions.

## 🎯 Objectives
- Practice filtering structured data.
- Use lists of dictionaries to represent student records.
- Apply conditional statements and logical operators.
- Understand filtering versus sorting.

## 🛠️ Tools & Technologies
- Python
- Jupyter Notebook
- VS Code
- Git
- GitHub

## 📚 Student Records
Each record contains Student ID, Name, Age, Marks, and Department.

## 🔍 Filtering Operations
- **Marks:** students with marks >= 85
- **Age:** students with age <= 20
- **Department:** students from AI & ML
- **Multiple conditions:** marks >= 80 and age <= 20

## 📈 Sample Results
| Filter | Condition | Students |
|---|---|---|
| Marks | >= 85 | Rahul, Priya, Neha, Riya |
| Age | <= 20 | Rahul, Aman, Neha |
| Department | AI & ML | Rahul, Neha |
| Multiple Conditions | Marks >= 80 and Age <= 20 | Rahul, Neha |

## 🎤 Interview Questions

### What is data filtering?
Data filtering is the process of selecting records that satisfy one or more conditions.

### How would you filter a Pandas DataFrame?
```python
df[df["marks"] >= 85]
```

### What is the difference between filtering and sorting?
Filtering selects records that meet a condition, while sorting changes the order of records.
